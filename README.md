## 🚀 Funktionen
- Zufällige Aufgaben (verschiedene Raten, Datengrößen, Auslastungen)
- Dunkles Design, einfache Benutzeroberfläche
- Antwortüberprüfung
- Schritt-für-Schritt-Lösungsweg

## 📱 Bedienung
1. Mit `Generieren` neue Aufgabe erstellen
2. Stunden/Minuten eingeben
3. Mit `Prüfen` Antwort kontrollieren
4. Mit `Zeigen` Lösung anzeigen
